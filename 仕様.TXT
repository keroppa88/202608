===============================================================================
  取得元・取得するモノ・取得方法  一覧
===============================================================================

取り方は2つだけ。

  (1) API があるなら API   … 返ってきたものを丸ごと保存する
  (2) 無ければ画面の全コピペ … ブラウザで開く → 描画を待つ →
                               画面に見えている文字を全部コピー → 丸ごと保存

抽出は、保存したものから後でやる。HTMLは読まない・抜かない。
詳しくは CLAUDE.md。

===============================================================================
  保存の決まり
===============================================================================

取れたものは、成功でも失敗でも data/raw/YYYY-MM-DD/ に丸ごと置く。
ボット判定の画面でも、エラー画面でも、そのまま保存する。
失敗の理由は、保存した全文を見れば分かる。

成否は、保存したものから抽出できた件数で後から決める。
