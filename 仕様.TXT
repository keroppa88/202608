===============================================================================
  取得元 / 蓄積するモノ / 取得方法
===============================================================================

ここに書いてあるものだけを取って蓄積する。書いていないものは取らない。

取り方は2つだけ。

  (1) API があるなら API   … 返ってきたものを丸ごと保存する
  (2) 無ければ画面の全コピペ … ブラウザで開く → 描画を待つ →
                               画面に見えている文字を全部コピー → 丸ごと保存

抽出は、保存したものから後でやる。HTMLは読まない・抜かない。CLAUDE.md 参照。
取れたものは成功でも失敗でも data/raw/YYYY-MM-DD/ に丸ごと残す。

取得元のあとに [算出のみ] の節がある。そこは外から取らない。
すでに蓄積したものだけを使って出す。

1. Yahoo Finance                                                        [API]
===============================================================================
アドレス   https://query1.finance.yahoo.com/v8/finance/chart/{シンボル}
取得方法   API。返ってきたJSONを gzip で丸ごと保存してから抽出
プログラム src/fetch_market.py
保存場所   生データ  data/raw/YYYY-MM-DD/yahoo_{シンボル}.json.gz
           蓄積      data/overseas_YYYY.csv（年ごと・四本値）
実行  市場ごとに1日の区切りが違うので、枠を4つに分ける

    market.yml            JST 火〜土 08:10  海外（下の3つと日本を除く）  90銘柄
    market-crypto.yml     JST 火〜土 09:10  暗号資産                    3銘柄
    market-commodity.yml  JST 月〜金 18:20  商品・先物                 16銘柄
    japan-stocks.yml      JST 月〜金 18:00  日本株・日本指数            24銘柄

  進行中の足は終値ではないので採らない決まりがある。区切りの前に取ると
  その日の足が採れず1日遅れるため、区切りを過ぎてから取る

    為替      22:00Z 区切り（ロンドン23:00）  → 08:10
    暗号資産  00:00Z 区切り                  → 09:10
    商品・先物 04:00Z 区切り（JST 13:00）     → 18:20
    米国株・欧州株・アジア株は 20:00Z までに引ける → 08:10 で足りる

  遅れても消えはしない。毎回1か月ぶんの足をまとめて取り込むので、
  次の実行で必ず入る

  通貨指数（ドル指数）は 08:10 の枠のまま。1日遅れることがある

                      data/raw/YYYY-MM-DD/nikkei_us_{ページ名}.txt
                      （一覧ページと記事ページの両方を丸ごと）
            蓄積      article/japan{YYYYMM}.txt / article/us{YYYYMM}.txt
                      掲載月ごと。取得月ではない
実行        nikkei-jp.yml  JST 月〜金 18:00
            nikkei-us.yml  JST 火〜土 08:00

14. 比率                                                            [算出のみ]
===============================================================================
取得はしない。保存済みのものから出すだけ。割り算するものと、
ページに出ている値をそのまま入れるものがある。

  ドル建て日経平均 = 日経平均 / ドル円（どちらも終値）

  NT倍率            = 日経平均 / TOPIX（どちらも終値）

  日経予想PER/プライム予想PER
  日経平均PBR/プライムPBR
                    = 日経平均とプライム全銘柄の比。割高・割安の差

  日本株イールドスプレッド
                    = プライム株式益回り − 長期金利
                      プライム株式益回り = 1 / プライム予想PER
                      長期金利 = 日本国債10年利回り

  プライム予想PER / 日経予想PER / プライムPBR / 日経平均PBR
                    … ページに出ている値をそのまま入れる。計算しない

  東証先導株比率1-N = 売買代金1位〜N位の合計 / 東証プライム売買代金
                      上位 5 / 10 / 20 / 30 の4本

  日経/プライム・売買代金比率
                    = 日経平均の構成銘柄の売買代金合計 / 東証プライム売買代金
                      ただし割り算はしない。日経のページに「対市場占有率」
                      として出ている値をそのまま使う

読むもの
  data/overseas_YYYY.csv       日経平均（^N225）の終値。1985年から
                               ドル円（USDJPY=X）の終値。1999年から
                               1. Yahoo Finance で取る
  data/jpx_index.csv           TOPIX の終値
                               7. JPX で取る。2004年から
  data/rank_trading_value.csv  東証の売買代金ランキング（円）
                               5. 日経 日本株ランキング で取る。1日30銘柄
  data/nikkei_kabu.csv         東証プライムの売買代金（百万円）
                               PER（株価収益率）・PBR（純資産倍率）
                               4. 日経 国内株式指標 で取る
  data/nikkei225_detail.csv    日経平均構成銘柄の売買代金の対市場占有率（％）
                               6. 日経 指数 で取る
  data/rates.csv               日本国債10年利回り（％）
                               12. tradingeconomics で取る

保存場所   蓄積  data/ratios.csv
実行       ratios.yml  JST 月〜金 18:30（もとになるものを取ったあと）

蓄積するモノ … 13本

    ドル建て日経平均
    NT倍率
    東証先導株比率1-5
    東証先導株比率1-10
    東証先導株比率1-20
    東証先導株比率1-30
    日経/プライム・売買代金比率
    日経予想PER/プライム予想PER
    日経平均PBR/プライムPBR
    プライム予想PER
    日経予想PER
    プライムPBR
    日経平均PBR
    日本株イールドスプレッド

  値は小数2桁。先導株比率と日経/プライムは％、NT倍率は倍
  NT倍率と先導株比率は分子と分母もそのまま残す。
  日経/プライムはページの値をそのまま入れるので分子・分母は空

  NT倍率は日経平均とTOPIXの両方がそろう日だけ出す。2004-04-01 から
  ドル建て日経平均は日経平均とドル円の両方がそろう日だけ。1999-01-04 から

  PBR はページに予想と前期基準の別が無く、純資産倍率が1つだけ出ている。
  それをそのまま入れている（名前に「予想」を付けない理由）

  日経平均の売買代金合計はページに「兆円・小数2桁」でしか出ておらず、
  そこから割って出すと 0.1ポイントほど狂う。同じ数字がページに
  「対市場占有率」として出ているので、そちらを使う

  どれかが欠けている日は計算しない。埋め合わせもしない。
  ランキングは当日ぶんしかページに出ないので、取り逃した日は後から取れない。

  毎回すべての日を計算し直す。何度流しても同じ結果になる

                 矢印キーで上下左右へ寄る

------------------------------------------------------- チャート（表から出す）

  銘柄名を押すと、いま画面に出ている分を画面中央に出す。外を押すと消える

  形             描画部分が 縦横 1 : 1.62。終値は折れ線、四本値はローソク足
                 ローソク足は上げた日が枠だけ、下げた日が塗りつぶし
  時間軸         月ごとに細い縦線と月の数字。足は日足
  価格軸         きりのいい数字に横線。線は4〜10本
                 step は R÷6 に最も近い「きりのいい数」（{1,2,2.5,5}×10ⁿ）
                 数字は3桁区切りなし・小数なし（目盛が1未満のときだけ小数）
  矢印キー       左右で隣の銘柄へ移る（表に出ている並びの順。端で回る）
                 上下で年を変える。表の年も一緒に変わる
                 その年に値が無い銘柄なら閉じる

  移動平均       20MA / 80MA / 200MA をチェックで重ねる。点線の形で見分ける
                 前年ぶんを読んで年初から描く
                 上下の幅は、押していなくても 200MA を入れて決める
                 （押すたびに縮尺が動くと傾きを目で比べられない）
  大きさ         ホイールで拡大・縮小。縦横の比は変えない。0.4〜4倍

------------------------------------------------------------------ チャート画面

  上のメニュー   左から  戻る / 相対／絶対 / ○○年 / Color / 線補完
                 ひとつずつ枠で囲う

  線補完         休みの日は値が無いので折れ線が切れる。押すと切れ目を
                 まっすぐ結ぶ。既定は「線補完なし」。相対でも絶対でも効く

  銘柄選択欄     既定5銘柄。＋ で増やす。最大10銘柄

  矢印キー       上下で年を変える。左右は横に寄せる

  大きさ         描画部分が 縦横 1 : 1.62。縦は画面の縦幅の 2/3 までに抑え、
                 横はそれに合わせて決まる。横がはみ出すときは横に合わせる

  相対           年初を100として1枚に重ねる。折れ線は銘柄ごとに色を変える
                 折れ線の右横に銘柄名と最終値（小数第一位）を同じ色で置く
                 名札が重なるときは押し下げる

  銘柄を外す     × を押す。指で押すと当てにくいので、▼の候補の筆頭にも
                 「× 削除」を置いてある
  絶対           そのままの値で描き、同じ時系列を上から縦に並べる

-------------------------------------------------------------------- 相関分析

  タイトル画面の「相関」から入る。通常画面の初期表示を遅くしないため、
  1999年以降の全年度データはこの画面を開いたときだけ読み、ブラウザ内に覚える

  対象銘柄       表で選んでいる銘柄を初期値にする。相関画面でも追加・削除できる
                 銘柄数の固定上限は置かない
  計算期間       有効な対応観測数で20日 / 60日 / 120日。既定は20日
  元系列         原則は日次騰落率。金利・政策金利は前日差
  日付対応       日本同士・米国同士・日本と韓国は同日
                 米国と日本／韓国は、米国日の後の最初の相手市場取引日
                 連休中の米国騰落率は複利合成し、休場日の0は作らない
  欠損           #N/A・空欄・非数値は除外。観測不足と分散0は N/A
  表示           20/60/120日の相関マトリクス、全ペア一覧と期間差、
                 中心性ランキング、相関集中度、集中度の全期間チャート
                 マトリクスのセルまたはペア行を押すと、そのペアの
                 20/60/120日ローリング相関を全期間で表示する
  操作           ペア一覧は各見出しで昇順・降順に並べ替え。チャートへ
                 マウスを重ねると日付と各期間の値を表示する
                 各指標タイトル横の丸い i を押すと、定義・算出法・意義、
                 市場間の日付対応、休場時の扱い、保留機能の説明を表示する
  計算           Pearson相関。相関は符号付きで平均し、絶対値にはしない
                 計算部分は correlation.js に分け、系列・日付対応・ペア結果を再利用する

------------------------------------------------------- 擬似スクリーンセーバー

  5分さわらないと、表もチャートも出したまま画面の上を動くものが出る。
  マウスを動かすかキーを押せば消える。消すための一押しは下の画面へ
  伝えないので、押した拍子に画面が変わることはない

  出る順   ムカデ×1 → 丸×1 → 蝶×1 → ムカデ×2 → 丸×2 → 蝶×2
           → ムカデ×3 → 丸×3 → 蝶×4。次はムカデ×1へ戻る
           一度の発動では1種類だけを出す。次に出す段階はブラウザに記憶する
           ムカデは波打って進み、体節が前の節の跡をたどる
           ボールはまっすぐ飛び、画面の枠で跳ね返る
           蝶は中央の細長い胴体と左右の翅を極細の隙間で分離する
           前翅は大きく、後翅はその約1/2サイズ。羽ばたかせてゆっくり飛ぶ
           触角を2本付ける。胴体は太く、進行方向の先頭は円形
           蝶の大きさは従来の2/3
           蝶はムカデ・丸と同じテーマ色

------------------------------------------------------------------------- 公開

  pages.yml。次の2つで走る

    main への push
    取得・算出のワークフローが終わったとき（workflow_run）

  取得のワークフローが打った push では公開が起きない。既定の GITHUB_TOKEN で
  push したコミットは別のワークフローを起こさない、という GitHub の決まりが
  あるため。それで workflow_run を合図にしている

  checkout は main の先端を明示して取る。workflow_run の既定は「起こした側が
  動いた時点のコミット」で、そのあとに取得が打ったコミットが入っていない
