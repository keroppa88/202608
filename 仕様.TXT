===============================================================================
  取得元 / 蓄積するモノ / 取得方法
===============================================================================

ここに書いてあるものだけを取って蓄積する。書いていないものは取らない。

取り方は2つだけ。

  (1) API があるなら API   … 返ってきたものを丸ごと保存する
  (2) 無ければ画面の全コピペ … ブラウザで開く → 描画を待つ →
                               画面に見えている文字を全部コピー → 丸ごと保存

抽出は、保存したものから後でやる。HTMLは読まない・抜かない。CLAUDE.md 参照。
取れたものは成功でも失敗でも data/raw/YYYY-MM-DD/ に丸ごと残す。

    「東証大引け」記事      1日1本（題名 / 掲載日時 / URL / 本文）
    「米国株 大引け」記事   1日1本（同上）

                      data/raw/YYYY-MM-DD/nikkei_us_{ページ名}.txt
                      （一覧ページと記事ページの両方を丸ごと）
            蓄積      article/japan{YYYYMM}.txt / article/us{YYYYMM}.txt
                      掲載月ごと。取得月ではない
実行        nikkei-jp.yml  JST 月〜金 18:00
            nikkei-us.yml  JST 火〜土 08:00

14. 売買代金の比率                                                  [算出のみ]
===============================================================================
取得はしない。保存済みのものから計算するだけ。

  東証先導株比率1-N = 売買代金1位〜N位の合計 / 東証プライム売買代金
                      上位 5 / 10 / 20 / 30 の4本

  日経/プライム・売買代金比率
                    = 日経平均の構成銘柄の売買代金合計 / 東証プライム売買代金
                      ただし割り算はしない。日経のページに「対市場占有率」
                      として出ている値をそのまま使う

読むもの
  data/rank_trading_value.csv  東証の売買代金ランキング（円）
                               5. 日経 日本株ランキング で取る。1日30銘柄
  data/nikkei_kabu.csv         東証プライムの売買代金（百万円）
                               4. 日経 国内株式指標 で取る
  data/nikkei225_detail.csv    日経平均構成銘柄の売買代金の対市場占有率（％）
                               6. 日経 指数 で取る

プログラム src/calc_ratios.py
保存場所   蓄積  data/ratios.csv
実行       ratios.yml  JST 月〜金 18:30（もとになる3つを取ったあと）

蓄積するモノ … 5本

    東証先導株比率1-5
    東証先導株比率1-10
    東証先導株比率1-20
    東証先導株比率1-30
    日経/プライム・売買代金比率

  値は％（小数2桁）。先導株比率は分子と分母もそのまま残す。
  日経/プライムはページの値をそのまま入れるので分子・分母は空

  日経平均の売買代金合計はページに「兆円・小数2桁」でしか出ておらず、
  そこから割って出すと 0.1ポイントほど狂う。同じ数字がページに
  「対市場占有率」として出ているので、そちらを使う

  どれかが欠けている日は計算しない。埋め合わせもしない。
  ランキングは当日ぶんしかページに出ないので、取り逃した日は後から取れない。

  毎回すべての日を計算し直す。何度流しても同じ結果になる

  data/raw/YYYY-MM-DD/     取ったものを丸ごと置く場所
                           画面の全コピペは .txt、APIの返答は .json.gz

                           同じキーの行は上書き。再実行しても二重にならない

  data/overseas_YYYY.csv   相場データ。1ファイルが大きくなりすぎないよう
                           年ごとに分ける（1999年以降）

  article/                 日経の記事。掲載月ごとのテキスト

  手で用意した過去分の取り込み
===============================================================================

`追加/` に置いた四本値のCSVを取り込む。日々の取得とは関係しない。
取得先から取れない過去分を入れるための道具。

    python3 src/import_added.py

入力の形はどれも同じ。

    Date,Open,High,Low,Close,Volume,TradingValue,UpLimit,LowLimit
    2026-08-10,4078.80,4111.35,4063.49,4100.61,,,,

取り込んだもの

    追加/日経平均.csv            → data/overseas_YYYY.csv（^N225）
                                 1985-04-01 から 10,278行

    追加/topix.csv              → data/jpx_index.csv  TOPIX
                                 2004-04-01 から 5,472日
    追加/topixグロース.csv       → TOPIX グロース          2009-03-24 から
    追加/topixバリュー.csv       → TOPIX バリュー          2009-03-24 から
    追加/東証REIT.csv           → 東証REIT指数            2026-01-28 から
    追加/東証REITオフィス.csv     → 東証REITオフィス指数
    追加/東証REIT住宅.csv        → 東証REIT住宅指数

    追加/東証グロース250.csv      → 東証グロース市場250指数
