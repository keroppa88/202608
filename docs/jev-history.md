# Jev週次判定・過去実績

対象は日経平均、TOPIX、NYダウ、SOX、S&P500、ナスダック総合の6指数。
比較は残り5指数とUSD/JPY、日本10年債利回り、米国10年債利回りの8系列に固定。
金利の変化は%ポイント差分、価格の変化は騰落率%。

毎週金曜までのデータを、日米と為替の週末取引終了後に評価する。休日は同週の最後の観測値を使う。
7日を超えて更新のない系列や250観測未満は失敗として保存を止め、他の値で埋めない。
過去5暦年は約261週、6指数で約1,566回。5/20/100営業日を1リクエストにまとめる。
現在の保存済み価格を判定日で切り、指標の最適化・類似局面・比較の計算前に未来の行を除く。
現在のデータ改訂やモデルの学習内容の影響までは排除できないため、リアルタイム運用履歴とは区別する。

翌週の最初の観測の始値を購入価格として5/20/100観測を評価する。
最高上昇率は期間内高値、最大下落率は期間内安値と購入価格を比較する。
日中の高値安値の順序が分からないため、最大ドローダウンは購入価格とその後の終値系列だけから計算する。
始値・高値・安値が欠ける実績はmissing_ohlc、期間未経過はpending。勝率や平均の分母に入れない。
各期間の最新買い度±5ポイント（両端含む、0～100に収める）、全判定、90%以上、80%以上、80～90%未満の件数、勝率、各指標の平均・中央値を銘柄別に集計する。
短期40・中期30・長期30なら、5日の35～45、20日の25～35、100日の25～35をそれぞれ独立に集計する。小数の買い度は丸めて分類しない。
20件未満は実績不足。週次の重複する期間を独立試行とみなさない。

## 実行

```sh
node --test tests/jev-history.test.mjs
node src/run-jev-history.mjs --mode prepare --limit 6
node src/run-jev-history.mjs --mode pilot --limit 12
node src/run-jev-history.mjs --mode backfill --limit 2000
node src/run-jev-history.mjs --mode update --limit 6
node src/run-jev-history.mjs --mode aggregate
```

既定は既存Cloudflare Workerを使う。APIキーをGitHubに登録し直す必要はない。
1分6回の制限に合わせて11秒の間隔を空ける。エラーは自動再試行せず止め、完了分を保存する。
ローカルで公式APIを直接使う場合のみ`--transport direct`と環境変数`TYPESAFE_API_KEY`を指定する。
キーを含むファイルをリポジトリに置かない。

`.github/workflows/jev-history.yml`が土曜10時JSTに6判定を追加し、全実績を更新する。
欠けた過去分を補完する場合は同ワークフローをmode=backfillで実行する。
100判定ごとにコミットし、400判定ごとに次の実行を自動起動する。
失敗で止まる場合も同じ引数で再実行すれば、保存済み判定は飛ばして続きから実行する。
実行終了後のworkflow_runがPagesの再公開を起動する。

`data/jev/<version>/<target>/<Friday>.json`に判定、入力SHA256とAPI usageを保存。
隣の`.input.json.gz`が完全な入力、`.response.txt`が元応答。
summary.jsonに銘柄別実績と最新判定、last-run.jsonに実行件数・参考料金・エラーを保存する。
モデル・質問・計算コードを変える場合はVERSIONを更新し、過去の結果と混ぜない。
改行を正規化した実装ハッシュが変わると同じVERSIONへの追記を拒否する（Windows/Linux共通）。
`jev-history.html`で保存済みの週次判定と実績を表示する。閲覧時にAPIは呼ばない。
通常の自由比較Jev分析の結果に、この固定比較の実績をそのまま当てはめない。
